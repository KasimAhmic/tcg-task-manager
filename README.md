# TCG Task Manager

TCG Task Manager is a simple mod for managing worker tasks from a single UI. No more chasing down workers and individually setting their tasks!

## Features
- Centralized task management UI
- Set tasks for multiple workers at once
- Set tasks for individual workers

## Future Plans
- Ability to schedule tasks
- Better integrated UI
- In-game smartphone app

## Installation
The mod is still a WIP so there is no release yet. If you would like to test it out, you can clone the repo and build it yourself.
